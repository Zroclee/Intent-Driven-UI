新增用户操作
1. 前往用户管理页面：http://localhost:5173/product/users
2. 点击新增“新增”按钮
3. 在弹窗中填写用户信息：用户名（input name="form-username"）、组织（select name="form-organization"）、角色（select name="form-role"）
4. 点击"确认"按钮
